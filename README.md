# 자기주도적학습코칭 완전정복

정적 사이트(HTML/JS) + Supabase. 학생은 로그인 없이 접속해 이름만 입력하고,
세계수도송 / 수업이론 / 세 가지 자가진단 중 하나를 골라 응답합니다.

**학생용** https://capitals-quiz-green.vercel.app
**교수자용** https://capitals-quiz-green.vercel.app/admin.html (비밀번호 jeonghwa2026)

## 구성

| 항목 | 내용 |
|---|---|
| 세계수도송 | 36문항 · 객관식 / 주관식 / 랜덤 객관식 / 랜덤 주관식 |
| 수업이론 | 문제은행 48문항 중 18문항 무작위 · 객관식(채점) / 주관식(채점 없이 모범답안 제시) |
| 학습동기 진단 | 20문항 4묶음 · 각 5~25점 |
| 학습스타일 진단 | 24문항 3묶음 · 각 8~40점 |
| 마인드셋 진단 | 12문항 2묶음 · 각 6~30점 |
| 조선의 왕 순서 | 4덩어리를 위 빈 칸에 넣기. 덩어리를 누르면 차례로 들어가고, 보라색 손잡이로 끌 수도 있다 |
| 조선왕조 이름 맞추기 | 27대 왕의 앞글자 옆에서 조·종·군 고르기. 결과에 왕마다 대표 업적과 조·종·군이 붙은 까닭을 함께 보여 준다 |
| 진달래꽃 · 서시 | 섞인 줄을 ▲▼ 로 옮기거나 보라색 손잡이로 끌어 원래 순서 맞추기 |
| 가고 싶은 나라 찾기 | 15문항 한 페이지 · 1번에서 고른 대륙 안에서 나와 맞는 4곳 추천 · 네 나라 모두 관광지 사진 3장 (채점 없음) |

## 갱신 절차

1. Supabase > SQL Editor 에서 `supabase-추가실행.sql` 실행 (최초 1회만)
2. GitHub > jykimsummer/capitals-quiz > Add file > Upload files
3. 이 폴더 **안의 파일 전체**를 선택해 드래그 → Commit changes
4. Vercel 이 1분 안에 자동 반영. 기존 주소 그대로

## 기록 규칙

- 시작 화면은 이름만 받고 모든 활동을 한 화면에 보여 준다. 주차는 받지 않으므로 기록에는 `week: 0` 으로 저장된다 (관리자 화면에서는 "기록" 열)
- 폰에서 끌기가 어려워, 손잡이를 보라색 동그라미(38px)로 키우고 조선의 왕은 눌러서 넣는 방식을 기본으로 했다 (`index.html` 의 `odClick` · `odArm`)
- 분반·학번은 받지 않음. DB 에는 section="-", student_id=이름 으로 저장됨
- 결과의 누적 기록은 숨김 (`index.html` 의 `hist-box`)
- 이론 주관식과 세 진단은 결과 화면에 누적 기록을 보여주지 않음 (DB에는 저장됨)
- 나라찾기는 점수가 없는 활동이라 0/0점으로 저장됨. 교수자 화면 `유형 > 가고 싶은 나라 찾기` 에서 고른 답과 추천 나라를 볼 수 있음
- 교수자 화면은 상단 '유형' 선택으로 분리해서 조회. 전체를 고르면 섞여 보임
- 교수자 비밀번호 변경: `update app_config set value='새비밀번호' where key='admin_password';`

## 문항 수정

- 수도 목록 → `quiz-data.js`
- 이론 문제은행 → `theory-data.js`
- 진단 문항·코멘트 → `diag-data.js`
- 관광지 사진은 위키백과에서 그때그때 불러옴. 바꾸려면 `country-data.js` 의 `spots` 에서 `p` 를 고칠 것 (`ko:문서제목` 또는 `en:Title`). 인터넷이 막히면 사진 자리에 관광지 이름만 표시됨
- 관광지는 나라마다 5곳을 두고, 응답자가 좋아한다고 한 것부터 3곳을 골라 보여줌. 분류 `t` 는 park(놀이공원)·museum(박물관·미술관)·nature(산·자연)·sea(바다)·heritage(유적)·city(도시)
- 순서 맞추기 문항 → `order-data.js` 의 `ORDER_SETS`. `layout` 이 `slots` 면 빈 칸에 끌어다 놓기, `reorder` 면 줄 목록에서 자리 바꾸기 (줄이 많으면 reorder 가 화면이 절반으로 짧다), `pick` 이면 앞글자 옆에서 보기 고르기 (`items` 는 `{q, a, w}`, 보기는 `choices`. `w` 는 결과 화면에 파란 글씨로 붙는 대표 업적·호칭 이유)
- 나라찾기 문항 → `country-data.js` 의 `COUNTRY_Q` · 나라 추가 → `COUNTRY_LIST` · 매칭 규칙 → `scoreCountry`
- 이론 출제 문항 수(18) → `index.html` 의 `THEORY_DRAW`
